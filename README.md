# Software Engineering Assignment

This repository contains the implementation of the Software Engineering technical assignment.

## Tasks

### [Task 1 – Age Classification](database/task-1-age/)
Oracle PL/SQL solution for configuration-driven age classification, including input validation and automated tests.

### [Task 2 – Calculate PI](database/task-2-pi/)
Oracle PL/SQL implementation of the Bailey–Borwein–Plouffe (BBP) formula with configurable precision, intermediate result storage and automated tests.

### Task 3 – Unpaid Invoices
SQL solution for identifying invoices that have not been fully paid.

### Task 4 – Modernization
Architecture and migration proposal for moving the functionality to a modern web-based solution.

### Task 5 – Full Stack Application
Java and TypeScript web application for visualizing the results of Tasks 1–3.
